# Koso-Server

NestJS backend for Koso — client & project management, meetings, documents, milestones, payment links & transactions, AI-powered PRD/pricing, and resume building.

## Setup

```bash
$ npm install
```

## Run

```bash
# development
$ npm run start:dev

# production
$ npm run build && npm run start:prod
```
